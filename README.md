# 별 모으기 놀이터 (Star Playground)

아이를 위한 로블록스 게임. 폭력·결제·채팅 유도 없이 달리고, 뛰고, 별을 모으는 게임입니다.

## 들어 있는 것
- 잔디 놀이터, 무지개 계단, 트램펄린 발판 6개
- 둥실둥실 떠 있는 별 40개 (먹으면 +1, 8초 뒤 다시 생김)
- 화면 오른쪽 위 점수판, 먹을 때 소리와 "+1" 글자

## 실행 방법
1. 로블록스 스튜디오(Roblox Studio)와 Rojo 설치
2. 이 폴더에서 `rojo serve` 실행
3. 스튜디오에서 Rojo 플러그인의 Connect 클릭 후 Play

## 숫자 바꾸기
`src/shared/Config.luau` 에서 별 개수, 점프 힘, 맵 크기를 바꿉니다.
